# Сводка — новостной бот + Telegram Mini App

Два раза в день (8:00 и 20:00 по Новосибирску) бот собирает свежие новости
из РБК, Интерфакса, Коммерсанта, ТАСС, BBC, TechCrunch и vc.ru. Затем Gemini
отбирает главное, пересказывает и пишет «что это значит для бизнеса», а бот
присылает в Telegram короткую сводку с кнопкой «Открыть сводку».

**Стоимость: 0 ₽.** Всё работает на бесплатных GitHub Actions, GitHub Pages
и бесплатном тарифе Gemini.

```
feeds.json                 ← список источников (можно добавлять свои)
scripts/digest.py          ← сбор, пересказ, отправка
.github/workflows/digest.yml ← расписание
docs/index.html            ← Mini App
docs/data/digest.json      ← свежая сводка (обновляется сама)
```

## Запуск — 6 шагов, около 20 минут

### 1. Репозиторий на GitHub
1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Нажмите **New repository** → имя `svodka` → **Public** → **Create**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите
   **содержимое** папки проекта (не саму папку) → **Commit changes**.

   ⚠️ Папка `.github` скрытая. На Mac сначала нажмите `Cmd + Shift + .` в Finder,
   чтобы её стало видно, и обязательно перетащите её тоже. Без неё не будет расписания.

> Репозиторий должен быть публичным: бесплатный GitHub Pages работает только так.
> Ключи при этом никто не увидит: они хранятся в Secrets (шаг 5).

### 2. Включить Mini App (GitHub Pages)
**Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save.**
Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/svodka/`.
Откройте его: вы увидите ленту со стартовой сводкой.

### 3. Бот в @BotFather
1. `/newbot` → придумайте имя → получите **токен** (выглядит как `123456:ABC...`).
2. `/newapp` → выберите бота → укажите название, описание, картинку 640×360
   → в поле **Web App URL** вставьте адрес из шага 2 → придумайте короткое имя, например `svodka`.
   Получите ссылку вида `https://t.me/ИМЯ_БОТА/svodka`: это и есть Mini App.
3. Необязательно: `/mybots` → бот → **Bot Settings → Menu Button** → тот же адрес.
   Тогда Mini App будет открываться кнопкой меню в чате с ботом.

### 4. Куда присылать сводку
- **Себе в личку:** напишите боту `/start`, затем узнайте свой id у @userinfobot (число).
- **Вам и команде (удобнее):** создайте канал, добавьте бота администратором.
  Для публичного канала id — это `@имя_канала`.

Можно указать несколько получателей через запятую: `@kanal,123456789`.

### 5. Ключи и настройки
В репозитории откройте **Settings → Secrets and variables → Actions**.

Вкладка **Secrets** → **New repository secret**:

| Имя | Значение |
|---|---|
| `GEMINI_API_KEY` | ключ из aistudio.google.com → Get API key |
| `TELEGRAM_BOT_TOKEN` | токен из шага 3 |
| `TELEGRAM_CHAT_ID` | получатель из шага 4 |

Вкладка **Variables** → **New repository variable**:

| Имя | Значение |
|---|---|
| `MINIAPP_URL` | ссылка `https://t.me/ИМЯ_БОТА/svodka` из шага 3 |
| `GEMINI_MODEL` | необязательно; по умолчанию `gemini-2.5-flash` |

### 6. Первый запуск
**Actions → Сводка → Run workflow.** Через 1–2 минуты сводка придёт в Telegram,
а Mini App обновится. Дальше всё работает само по расписанию.

## Если что-то не так

- **Сводка пришла без пересказов, только заголовки.** Gemini не ответил: неверный
  ключ, исчерпан лимит или устарело имя модели. Бот специально продолжает работать
  в таком режиме. Проверьте ключ или задайте актуальную модель в `GEMINI_MODEL`.
- **Сообщение не пришло.** Откройте Actions → последний запуск → шаг
  «Собрать и отправить сводку». Внизу видна ошибка Telegram: обычно это неверный
  `TELEGRAM_CHAT_ID` или бот не добавлен в канал администратором.
- **Сводка пришла с опозданием на 5–20 минут.** Это нормально: GitHub запускает
  задачи по расписанию с небольшой задержкой.
- **Mini App показывает старую сводку сразу после сообщения.** GitHub Pages
  обновляется 1–2 минуты. Нажмите кнопку обновления в правом верхнем углу.

## Как поменять

- **Источники:** `feeds.json`. Добавьте строку с названием, RSS-ссылкой и рубрикой
  (`Бизнес`, `Россия`, `Мир` или `Идеи`).
- **Время отправки:** `.github/workflows/digest.yml`, строки `cron`. Время там
  указано по UTC: Новосибирск = UTC + 7, то есть 8:00 → `0 1 * * *`.
- **Что считать важным:** текст запроса к ИИ, переменная `PROMPT` в `scripts/digest.py`.
